## 1. 공통 규칙

### 1-1. 유료 콜 예산

- Gemini는 **유료**다. 실크롤은 **대표가 명시적으로 요청할 때만** 돌린다.
- **한 라운드의 실제 콜 수 = 최대 4, 전형 2.** 조사 1 + (칩이 `CHIP_TARGET`(10) 미만이면
  **서버가 자동으로** 병렬 재시도 최대 2, 1회만) + 생성 1. 근거: `enrich.ts` `CHIP_TARGET = 10`,
  재시도 트리거 블록. → **"2콜 예산"을 절대 상한처럼 말하지 마라. 재시도는 네가 안 눌러도 발동한다.**
- 실측 단가(정본 §1): 조사 **3~5원 / 7~11초** · 소개서 초안 **70~100원 / 24~40초** ·
  DNA **3~7원 / 3~8초** · 리포트 **25~35원 / 20~25초**.
- 개선은 "호출 수 추가"가 아니라 **"같은 호출에 더 좋은 입력·지시"**로 한다. 네이버 검색은 일 25,000회 무료라 쿼리 확장은 부담 없다.
- **UI 배선만 볼 거면 로컬 `ENRICH_FORCE_MOCK=1`** — 0콜로 화면까지 간다(`enrich.ts` mock 분기).
- ⚠️ **크롤을 트리거하는 엔드포인트를 폴링으로 두드리지 마라**(07-15에 grounding 18연발·레이트리밋 유발).
  배포 확인은 충분히 기다렸다가 단일 콜, 또는 크롤 없는 경로로.

### 1-2. ⭐캐시가 A/B를 오염시킨다 — 우회 프리미티브 3종

"같은 입력으로 두 번 뽑기"가 그냥은 안 된다. 세 군데에 캐시가 있다.

| 어디 | 동작 | 우회 |
|---|---|---|
| 위저드 생성 | 입력 키가 직전과 같으면 **생성 콜을 건너뛴다**(`EnrichWizard.tsx`, `genKey === lastGenKey` → 콜 절약) | 입력을 바꾸거나, UI 말고 스크립트 하네스로 돌린다 |
| 리포트 | 쌍별 최신 행 + 양쪽 DNA non-stale + 행이 DNA보다 최신이면 **저장본 즉시 반환(0콜)** | `POST /api/collab-report`에 **`force: true`**(A/B용으로 이미 만들어 둔 프리미티브, `route.ts`) |
| Brand DNA | **stale일 때만** 재생성 | 아래 참조 |

**DNA stale 판정은 시각이 아니라 소개서 내용 지문(`input_hash`)이다**(`collab-report.ts` `isDnaStale`).
DNA를 `brands` 행에 저장하면 `updated_at` 트리거가 발화해 **저장 행위가 그 DNA를 낡게 만드는 순환**이
있었고(07-26 실장애: 매 요청 3콜·리포트 캐시 영구 미스), 지문 판정으로 고쳤다.
⚠️ **그래서 DNA 프롬프트나 출력 항목을 바꾸는 A/B는 지문이 안 바뀐다 → 영원히 옛 DNA가 캐시된다.**
그런 개정은 `dna-pool.ts`의 **`DNA_REFRESH_BEFORE`를 올려야** 실제로 재생성된다.

리포트 모델 비교는 같은 라우트의 **`model` 파라미터**(화이트리스트 `gemini-2.5-flash`·`gemini-3.6-flash`·`gemini-3.1-pro-preview`)로 한다. 일반 UI는 `model`·`force`를 안 보내므로 기본 경로에 영향 없다.

### 1-3. 판정 — 대표 블라인드 + 계량기

- **최종 판정은 대표가 라벨을 가린 채 고른다.** 이게 정본 관례다(07-26 리포트 3파전, 07-27 소개서 글월·레이지오터 3파전).
- 제시 형태 = **Claude 아티팩트 페이지 1개**에 안별 탭/열 + 출력 전문 + 규칙 점검표.
  과거 9건의 URL이 정본 §6에 있다(⚠️아티팩트는 기본 비공개, 대표 계정에서 열림).
- **원가 계량기 로그 없이 판정하지 마라.** 모든 Gemini 콜이 `[cost] 라벨 model=… 22.3초 in=… out=… think=… = 68.4원`을
  남긴다(`ai-cost.ts`, 표기는 초 단위). 라벨: `enrich:search:라운드N` · `enrich:소개서초안` · `dna(slug)` · `report`.
  요청 합계는 `[cost] TOTAL …`.
- ⚠️ **1회 측정은 편차다.** "3.6이 +9.8초 느리다"가 재보니 반대였다(정본 §5). **최소 2업체**로 돌려라.
- **사고(thinking) 토큰이 시간·원가의 최대 변수**다. 화면에 안 보이는데 **출력 단가로 과금**되고
  원가의 절반을 넘기도 한다. DNA는 사고를 꺼서 **48초/85원 → 25~28초/35원**이 됐다.
- 셀 수 있는 지표로 적어라: ①소개서 **고유명사 인용 수**(2/9 → 7/9 식) ②**규칙 위반 건수**(금지 어미·상투어)
  ③사실 오류 0(특히 운영 정보·연도·매체명) ④빈 필수 항목 0 ⑤시간·원가·사고 토큰.

### 1-4. 프롬프트를 건드리는 A/B면 **파서를 같이 본다**

🚨 07-27 하루에 같은 계약이 **세 번** 깨졌다. 전부 *"검색이 못 찾았다"*처럼 보였지만 **우리가 못 읽은 것**이었다
(마크다운 소제목 `**정체**`, `"이름 — 설명"`인데 파서는 콜론만, 분리 정규식과 보호 집합 불일치).

- **프롬프트는 요청이고 보장은 파서가 한다.** 출력 형식을 바꾸면 파서를 같은 커밋에서 확인해라.
- 증상이 "모델이 못 찾았다"로 보이면 **raw output을 먼저 열어봐라.** 파서 탓일 때 재시도·모델 업그레이드는 돈만 태운다.
- **회귀 세트(오프라인·콜 0)** — enrich 손댔으면 필수:
  - `npx tsx scripts/test-enrich-guards.ts` — **208종**(오귀속·칩 추출·링크·정규화)
  - `npx tsx scripts/test-dna-stale.ts` — stale 판정 회귀(캐시 순환 재발 가드)
  - `npx tsx scripts/test-dna-signature.ts` — signature 원문 대조 게이트
- **Gemini 교차검증 관례**: 프롬프트 최종본은 임시 tsx 스크립트로 프로젝트 안에서 점검하고 실행 후 삭제한다.
  단 **유료 호출 수는 늘리지 않는다.**

## 2. 유형 ① 재료 A/B — 제품 단독 vs 사람 리서치

핵심 질문: **"사람이 리서치로 보강하면 뭐가 좋아지는가? 그 재료는 파이프라인 어느 단계에서 유실됐는가?"**

- **A = 베이스라인**: 지금 제품이 **혼자** 만들 수 있는 최고치. 사람 리서치 개입 0.
- **B = 보강**: A와 동일한 크롤 결과 위에 Claude의 직접 리서치를 얹은 것.
- ⚠️ **B에서 크롤을 다시 돌리지 않는다.** 재실행하면 "보강 효과"와 "크롤 랜덤성"이 섞인다. 변수는 하나여야 한다.

### 2-1. A버전 생성

prod `https://collab5.co.kr/register`(= `collab5.vercel.app`)의 AI 위저드에서. **대표 계정으로 로그인된 세션**에서 진행하고,
로그인이 필요하면 대표가 직접 입력한다(에이전트는 비밀번호를 다루지 않는다).

위저드 스텝 = `chips → confirm(별표) → links → fields → oneLiner → desc → story`(`EnrichWizard.tsx`).

1. **상호·지역·업종만** 입력
2. 크롤이 제안하는 **칩 전부 선택**
3. 별표(확신도) — **최대 6개**(`MAX_STARS = 6`, 07-22에 4→6. 생성 프롬프트 `slice(0,6)`와 동기)
4. 링크 확인 (크롤이 찾은 인스타·홈피 등이 실제 업체 것인지)
5. `fields` — 상호·주소 등 확인. **협업 칩·제공 콜라보 텍스트도 AI가 프리필한다**(offersHint, 07-22). 고치지 마라.
6. 한줄 소개(5개)·자세히 소개(6개) **후보 중 최선 1개 선택**, `story` 체크리스트도 **선택만**
7. 저장 → **`/m/{slug}` URL을 즉시 기록**

원칙: 선택지 안에서 고르는 것까지만, **텍스트를 쓰거나 고치는 개입은 0**.

### 2-2. B버전 생성

1. A와 **동일한 베이스**에서 시작(크롤 재실행 금지). A 저장 직후 같은 위저드 상태에서 잇거나, A를 복제해 수정 화면에서 보강.
2. Claude가 브라우저로 **직접 리서치** — 인스타 바이오·포스트(사장님이 직접 쓴 텍스트) / 보도기사 / 네이버 블로그(사장님 운영 우선).
3. 얻은 **사장님 직접 작성 텍스트**를 근거로 섹션 보강. **창작 금지**, 항목마다 출처를 메모(비교표 재료).
4. 상호에 구분자를 붙여 저장(slug는 안전 — §5 참조).

### 2-3. 비교표 → 유실 지점 역추적

| 섹션 | A | B | 차이 | 차이의 출처 |
|---|---|---|---|---|
| 한줄 소개 / 자세히 / 활동 / 콜라보 / 소개된 곳 / 공간 / 키워드 | | | | (인스타·기사·블로그 중 무엇) |

"차이의 출처"가 핵심이다. B 우위 재료마다 세 갈래로 역추적한다:

1. 그 소스를 파이프라인이 **아예 안 봤나?** (검색 쿼리·크롤 대상 문제 → `enrich.ts` `searchStrategy`)
2. 봤는데 **추출에서 버렸나?** (조사 프롬프트 `promptFor` / **파서** — §1-4를 먼저 의심해라)
3. 추출됐는데 **생성이 안 썼나?** (`OPTIONS_SYSTEM` / 후보 선택)

유실 지점별 개선안을 우선순위 목록으로 정리하고, 적용 후 **같은 업체로 C버전**을 만들어 **B와 재비교**한다.
C가 B에 근접하면 성공. 최종적으로 **최고 버전 하나만 남기고**, prod 테스트 데이터 **삭제는 대표가 직접** 한다
(삭제 SQL만 알려줘라. 테이블은 `brands`. /my 삭제는 하드 delete가 아니라 `status='inactive'` 소프트 삭제다).

## 3. 유형 ② 로직 A/B — 모델·사고량·프롬프트

### 3-2. 세대별 API 차이 (여기서 제일 많이 깨진다)

- **`thinkingBudget:0`은 2.5 계열만.** 3.x는 400으로 거부하고 `thinkingLevel`(minimal/low/medium/high)만 받는다.
  코드가 `model.startsWith("gemini-3")`로 갈라 붙이고, 그래도 400이면 옵션 없이 1회 재시도한다.
- **SDK 열거값은 대문자**(`LOW`/`HIGH`) — env는 소문자로 받아 `toUpperCase()`.
- **`low`가 사고 0을 보장하지 않는다** — 프롬프트가 어려우면 쓴다(실측 0 → 1,677).
- **"3.x는 temperature 지원 중단"은 사실이 아니다** — `3.6-flash`는 0.4·1.0·1.4를 다 받는다(실측 07-27, `074c4db`).
  이 전제로 모델 교체를 포기하지 마라. (구글 공지와 실측이 다른 케이스다.)
- **`gemini-2.5-pro`는 신규 사용자 404**("no longer available", 07-26 실측). 하드코딩 금지.
- 사용 가능 모델 목록: `curl "https://generativelanguage.googleapis.com/v1beta/models?key=$GEMINI_API_KEY"`.
- 단가표에 없는 모델은 계량기가 **0원 + ⚠️표시**로 찍는다(`ai-cost.ts`) — 모델을 새로 넣으면 단가도 넣어라.

### 3-3. 하네스 — UI 말고 스크립트로 돌려라

위저드·시트로 A/B를 돌리면 캐시(§1-2)와 사람 손이 변수로 낀다. **prod DB의 실브랜드를 읽어 생성만 돌리고
DB에는 안 쓰는 스크립트**가 정석이다. 실전 예: `scripts/generate-sample-report.ts`
(`set -a; source .env.local; set +a; npx tsx scripts/generate-sample-report.ts` — `repo.getMakerBySlug`로 읽고
`generateDna`/`generateReport`를 직접 호출, 결과는 파일로 씀).

임시 하네스는 `scripts/x*.ts`로 만들고 **실행 후 즉시 삭제**한다. 실크롤 A/B는 같은 방식으로
`enrichResearch`/`enrichOptions`를 직접 호출하면 위저드 캐시를 피할 수 있다.

## 4. ⭐저장 없는 검증 라운드

"방금 배포한 기능이 실제로 동작하나?"만 확인하면 될 때는 **저장하지 않는다.**
위저드를 끝까지 돌려 **폼까지만 진입한 뒤 DOM으로 프리필 값을 읽고 탭을 닫는다.**

- prod에 테스트 소개서가 안 쌓인다(대표가 나중에 지울 것 0건).
- 확인 가능: AI가 채운 모든 값(칩 ✓ 상태, textarea `.value`, 배지 유무), 한줄·자세히 후보 전문, 활동/콜라보/공간 힌트.
- 확인 **불가**: 저장 로직·`/m` 렌더 결과. 그건 정식 라운드에서.
- 유료 콜은 정식 라운드와 동일하게 든다(생성까지 가므로 **조사+생성 ≈ 75~105원**, 재시도 붙으면 더).
  **UI 배선만 볼 거면 로컬 `ENRICH_FORCE_MOCK=1`으로 0콜.**

⚠️ **placeholder를 값으로 오판하지 마라.** 회색 예시 문구는 `placeholder` 속성이다. `javascript_tool`로 `.value`를 읽어 판정한다.

## 5. Vercel 로그 판독 — 파이프라인이 실제로 돌았는지

생성물만 보면 "재료가 안 들어온 것"과 "들어왔는데 생성이 안 쓴 것"을 구분할 수 없다.
**vercel.com → 프로젝트 → Logs → 검색어 입력.**

| 로그 | 의미 |
|---|---|
| `[enrich] search {"plan":[…],"grounded":N}` | 조사 콜이 몇 라운드 돌았고 몇 개가 접지됐나 |
| `[enrich] instagram digest: bio+Nposts (@handle)` | 인스타 발췌가 서버에 도착(N=캡션 수) |
| `[enrich] instagram profile fetch failed …` | 인스타 fetch 실패(차단·타임아웃) |
| `[article-excerpts] {"urls":N,"got":M}` | 기사 본문 발췌 성공 M건 |
| `[homepage-digest] {…}` | 홈페이지 딥리드 결과 |
| `[enrich] gemini … 비접지 → 폐기` | grounding 없이 생성 → 폐기됨(상상 업체 방지) |
| `[cost] 라벨 model=… 초 in/out/think = 원` | **콜별 실측 원가·사고 토큰**(A/B 판정 근거) |
| `[cost] TOTAL …` | 요청 1건 합계 + 사고 비중 % |
| `[collab-report] cache-miss … force=… latest=… fromDna=… toDna=…` | 리포트 캐시를 왜 못 맞췄나 |
| `[collab-report] … candidates=[…] picked=N ideas=N` | 접점 후보 전문·자기채점·서버 선발 결과 |
| (아무것도 없음) | 그 재료가 서버까지 전달조차 안 됨 → 배선 버그 |

**판정 분기**: 로그에 재료가 있는데 생성물에 없다 → **프롬프트 문제**. 로그 자체가 없다 → **수집·배선 문제**.
그런데 **셋째 가능성이 파서**다(§1-4) — raw 출력을 확인하기 전에 프롬프트를 고치지 마라.

⏰ **로그 보관 기간이 짧다(07-22 관측 ~1시간).** 크롤 직후 바로 확인하고, 대표에게 부탁할 땐 "지금 봐달라"고 함께 알린다.

## 6. slug — 우회 불필요

**상호에 A/B/C를 그냥 붙여도 된다.** `slugify()`가 ASCII만 남겨 "캔앤코르크A" → `/m/a`가 되던 문제는
2026-07-22에 `src/lib/actions.ts`에서 고쳤다:

```ts
return ascii.length >= 3 ? ascii : "m-" + Math.random().toString(36).slice(2, 8);
```

- 실측: "캔앤코르크C" → `m-gnd43q` ✅ / 영문 상호(ASCII 3자 이상)는 그 ascii가 그대로 slug.
- slug는 랜덤이라 **생성 즉시 `/m/{slug}`를 기록**해라(다시 유추 불가).
- `updateMakerContent`는 slug를 변경 대상에서 제외하므로(`Omit<…, "slug">`, `repo.ts`) 저장 후 상호를 바꿔도 slug는 고정된다.

## 7. 브라우저 자동화 함정 (실측)

- `read_page`의 ref는 **뷰포트 안에 있을 때만 유효**. 스크롤 후엔 다시 read_page.
- React 배칭 때문에 **한 번의 JS 실행에서 여러 클릭을 하면 마지막 것만 반영**된다. 칩·키워드는 **하나씩** 클릭.
- 클릭 후 화면이 안 바뀐 것 같으면 `screenshot`으로 **강제 페인트** 후 `read_page`. 백그라운드 탭은 페인트가 멈춘다.
- **최종 저장 버튼은 ref 실클릭**(JS dispatch 금지).
- 🪤 **저장이 조용히 실패하면 세션 만료를 의심해라.** Claude 내장 브라우저는 access token(기본 1h) 갱신이 안 붙어,
  `/my`는 로그인처럼 보여도 저장 서버 재검증에서 소유자로 인정받지 못한다.
  → 대표의 실제 크롬을 `mcp__claude-in-chrome__*`로 조종하고, **로그인 제출은 대표가 직접** 누른다.
